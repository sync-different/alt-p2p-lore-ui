# alt-lore Desktop 0.1.0

First release. alt-lore Desktop is a desktop app for working with [Lore](https://github.com/EpicGames/lore) — Epic Games' version control system for huge binary assets — on repositories **wherever they live**: on your network by address, or on someone else's machine over an encrypted peer-to-peer tunnel. No repo server to rent, no cloud storage, no terminal.

Everything is in the box: the `lore` CLI, the [alt-p2p-lore](https://github.com/sync-different/alt-p2p-lore) tunnel, and a Java runtime. Install one app; there is no step two.

## Highlights

- **Hosts, both kinds** — peer-to-peer through a coordinator (with automatic encrypted relay fallback when networks are strict — the status dot honestly shows which path you got), or direct to any address you can reach.
- **Workspaces** — one tab per working copy, each pinned to the identity it acts as; two clones of one repo can be two different people.
- **The full flow, point and click** — clone, stage, commit, sync, push, branches, and per-file conflict resolution ("keep my version / take the host's").
- **Progress you can trust** — clone and sync show bytes, speed and time remaining measured from what's actually on disk; long operations never leave you staring at a frozen button.
- **The app tells you where you stand before you act** — *"the host has work you do not — sync to get it"* — instead of failing after.
- **Locks, visible** — see who holds a file, take and release your own. (Advisory, as Lore's locks are; on hosts without sign-in, owners can't be told apart.)
- **A console that shows everything** — every `lore` command the app runs, streamed live. When something fails, the answer is usually right there.

## Install

- **macOS (Apple Silicon):** `alt-lore-desktop_0.1.0_aarch64.dmg` — signed and notarized; opens with no warnings.
- **Windows (10/11, x64):** `alt-lore.Desktop_0.1.0_x64-setup.exe` — signed by Alterante, Inc. While the certificate is new to SmartScreen you may still see "unrecognized app"; choose **More info → Run anyway**. This fades as downloads accrue.
- **Linux:** no build yet.

Connecting to a host — especially one that requires sign-in — needs a few details from whoever runs it: see [SETUP.md](https://github.com/sync-different/alt-p2p-lore-ui/blob/main/SETUP.md) (identity port, sign-in token, and the one-time CA trust step for private-CA hosts; the app names that last one when it's the problem).

## Known limitations

- macOS build is Apple Silicon only (an Intel/universal build needs an x86-64 `lore` we don't ship yet).
- One P2P tunnel per host at a time — the identity port binds once; the app refuses a second connect with a plain message.
- On very large repositories, Lore's own change-scan re-hashes edited files; the app shows "Scanning…" and waits it out rather than guessing.
- Windows only: mid-transfer speed can briefly over-read while Lore preallocates files; totals and final averages are correct.
